Come leggere i numeri

  • GitHub aggiorna i conteggi con qualche minuto di ritardo, a volte di più: un download appena fatto può comparire dopo.
  • GitHub conta ogni scaricamento di un file, non le persone. Lo stesso utente che reinstalla conta due volte, e anche i tuoi download di prova sono inclusi.
  • Su Windows e Linux l'aggiornamento automatico scarica lo stesso file del primo download (setup.exe, AppImage), quindi lì installazioni e aggiornamenti non si possono separare. Su Mac sì: chi installa scarica il dmg, l'aggiornamento scarica lo zip.
  • Le copie Naibi-…-mac-*.zip esistono solo perché i Mac con la vecchia app Naibi trovino l'aggiornamento. Nelle versioni prima del cambio di nome, i file Naibi erano gli unici e contano normalmente.
  • Restano fuori i file tecnici (latest*.yml, *.blockmap), che l'app legge per controllare e scaricare gli aggiornamenti.
  • La versione web (stella.lucadj.eu/app/) non passa da GitHub Releases e non è contata qui.
